# Amazon Sales Analysis — Power BI Dashboard

## 📊 Project Overview

This project is an **Amazon Sales Analysis Dashboard** created using **Microsoft Power BI**. The dashboard transforms Amazon sales data into meaningful business insights through interactive visualizations, KPIs, and analytical reports.

The main objective of this project is to analyze **sales performance, product trends, customer behavior, and overall business performance** to support data-driven decision-making.

## 🎯 Objectives

* Analyze overall Amazon sales performance
* Track key sales and revenue KPIs
* Identify top-performing products and categories
* Analyze sales trends over time
* Understand customer purchasing patterns
* Compare product/category performance
* Build an interactive and user-friendly business intelligence dashboard

## 🛠️ Tools & Technologies

* **Power BI**
* **Power Query** – Data cleaning and transformation
* **DAX** – Measures and calculated columns
* **Data Modeling** – Relationships and analytical model
* **Microsoft Excel/CSV** – Source data

## 📈 Key Dashboard Features

The dashboard includes:

* Total Sales
* Total Orders
* Total Quantity Sold
* Average Sales
* Sales Trend Analysis
* Category-wise Sales Performance
* Product-level Analysis
* Top & Bottom Performing Products
* Interactive filters and slicers
* Dynamic visualizations for business analysis

## 🔍 Analysis Performed

### Sales Analysis

Analyzed overall sales performance and identified trends and fluctuations in revenue.

### Product Analysis

Identified products contributing the most and least to overall sales.

### Category Analysis

Compared different product categories to understand their contribution to total sales.

### Time-Based Analysis

Analyzed sales performance across different time periods to identify trends and patterns.

### KPI Analysis

Created key performance indicators using DAX to provide a quick overview of business performance.

## 🧮 DAX & Data Modeling

DAX was used to create calculated measures and KPIs required for the dashboard.

The data model was structured to enable efficient filtering, aggregation, and analysis across different dimensions.

## 📊 Dashboard

The final Power BI dashboard provides an interactive interface where users can use slicers and filters to explore sales performance from different perspectives.

> **Note:** The `.pbix` file contains the complete Power BI dashboard, data model, transformations, and DAX calculations.

## 💡 Key Insights

The analysis helps identify:

* Which products generate the highest sales
* Which categories perform best
* Sales trends over time
* Products/categories requiring improvement
* Overall business performance
* Areas that can potentially contribute to future sales growth
